# Claudia

![Claudia](https://user-images.githubusercontent.com/69826495/145114783-9377d505-96f0-4ca2-9c3a-e4ac3f289a7a.jpeg)

A bare-bones, PM-based riff on the Le Chiffre 30% keyboard by tominabox1 https://github.com/tominabox1/Le-Chiffre-Keyboard.git

* Keyboard Maintainer: [OTTIMO](https://github.com/subottimale)
* Hardware Supported: Claudia (https://github.com/subottimale/Claudia)
* Hardware Availability: make your own

Make example for this keyboard (after setting up your build environment):

    make claudia:default

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).
